# Codex dev login

Start
1. npm install
2. npm run dev
3. Open de forwarded preview URL uit de Ports tab

Login
1. Gebruik Email Password login in dev
2. Gebruik credentials uit environment variables:
   CODEX_DEV_EMAIL
   CODEX_DEV_PASSWORD
3. Print of log de secret waarden nooit
4. Commit nooit bestanden met secrets, ook geen .env.local met wachtwoorden
